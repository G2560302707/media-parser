# media-prism 实现机制与支持范围

这份说明给内部研发 / 运维：功能是怎么接到 HTTP 上的、每个平台解析器实际在干什么、哪些算正式支持。

---

## 1. 落地形态

media-prism 是 **Flask 应用 + 平台解析器插件**。仓库入口 `app.py`，生产由镜像里的 Gunicorn 加载 `app:app`。

两种运行模式：

| 模式 | 环境变量 | 对外开放时 |
| --- | --- | --- |
| 运营模式（要用这个） | `API_ONLY=false` | 有后台、API Key、积分、QPS、调用日志 |
| 纯引擎 | `API_ONLY=true` | 免鉴权、不写库。只适合内网调试，不能对公网 |

对外 API 的实现文件：`src/api/parse.py`。标准入口：

- `POST|GET /api/v1/parse` — 给客户
- `POST /api/parse` — 运营模式下是前台体验，有 IP 频控；微服务模式下与 v1 一样免鉴权
- `GET /api/health` — 存活探针

## 2. 一次解析怎么走完

调用方传入整段分享口令或纯 URL。服务端不做浏览器渲染。

```
text/url
  → UrlParser.get_url        从文本抠出 http(s) 链接，抖音短链去掉口令数字尾巴
  → WebFetcher.fetch_redirect_url   跟 302，最多 5 跳；遇到 /login /captcha 停住
  → UrlParser.get_platform   用 configs 里 DOMAIN_TO_NAME 认平台
  → ParserFactory.create_parser(平台, 落地 URL)
  → 解析器构造时拉数（各平台自己的 API / HTML）
  → get_title / get_real_video_url / get_image_list / …
  → 统一成 JSON：HTTPS、title 兜底、图集第一张当封面
```

超时：整次解析约 90 秒。工厂用 `pkgutil` 扫描 `src/parsers/`，`@register_parser("抖音")` 自动注册，加平台不用改工厂。

Cookie 读取顺序（`src/utils/cookie_manager.py`）：

1. 后台 SQLite 系统设置（最高，热更新）
2. 环境变量 `DOUYIN_COOKIE` / `XHS_COOKIE` 等
3. 别名变量
4. 空 → 匿名协议

## 3. 三个主平台实际怎么实现

### 3.1 抖音 `DouyinParser`

短链 `v.douyin.com` → 分享页 `iesdouyin.com/share/video|note/{id}`。

| 作品类型 | 主路径 | 失败后 |
| --- | --- | --- |
| `/video/` 常规视频 | 移动端 Feed（`amemv.com` / `snssdk.com`，免 Cookie） | 分享页 HTML 里的 `_ROUTER_DATA` → 再不行才打 Web 详情接口 |
| `/note/` 图文 / 实况 | **先打** PC Web 详情接口（实况 MP4 只在这里） | 403 则分享页 SSR，通常只剩静图 |
| 音乐 / 合集 / 放映厅 | 各自 Web API | SSR |

这就是实测差异的根因：普通视频匿名即过；实况匿名只有静图；火狐登录 Cookie 带上 `UIFID` 后 Web 详情接口才给出 `live_photo_url`。

图集取无水印原图字段，避开带水印的 `download_url_list`。分享页若给出 `/playwm/`，实现里会改成 `/play/` 并尝试升到 1080p。这是选流，不是对画面去标。

### 3.2 小红书 `XiaohongshuParser`

跟短链时保留 `xsec_token`。拉笔记 HTML，抽 `window.__INITIAL_STATE__`。PC UA 优先，失败换移动 UA。跳到 `/login` 则报需要 Cookie。

本仓库测试集三条短链在家庭宽带匿名下通过，含一条实况。机房 IP 不保证。

### 3.3 哔哩哔哩 `BilibiliParser`

识别 `b23.tv` / `www.bilibili.com`。走站点公开接口拿播放地址。测试集 BV 视频匿名通过。

## 4. 统一输出（调用方只认这一套）

成功时 `data` 字段稳定，平台差异被抹平：

| 字段 | 含义 |
| --- | --- |
| `platform` | 中文平台名，如 `抖音` |
| `video_id` | 从落地 URL 抽出的作品 ID |
| `title` / `desc` | 无标题时用文案填 title |
| `video_url` | 主视频 |
| `video_list` | 仅多视频时出现，首项等于 `video_url` |
| `cover_url` | 无封面则用图集第一张 |
| `image_list` | 字符串=静图；对象=`url` + 可选 `live_photo_url` + 可选 `live_asset_url`（合成后的系统实况 JPEG） |
| `audio_url` / `subtitles` | 有则给 |
| `author.nickname` / `author_id` / `avatar` | 有则给 |
| `is_preview` / `full_duration` | 仅试听音频 |

失败时 `data` 为 `null`，看 `error_code`。完整表见接口文档。

## 5. 官方声明支持范围

以下来自项目 README 矩阵（50 个解析器文件）。带 `*` 表示官方水印可能仍在画面里。

**短视频 / 图文：** 抖音、小红书、视频号、微信公众号、快手、哔哩哔哩、闲鱼、拼多多、Soul、剪映、快影、皮皮搞笑、微视、AcFun、西瓜、头条、绿洲、皮皮虾、新片场、好看、梨视频、微博、知乎、美拍、最右、得物、LOFTER、虎牙（偏直播流）

**AI 生成：** 豆包、即梦*、小云雀*、可灵、海螺、夸克 AI、通义千问、腾讯元宝*、星绘 AI

**音乐：** 汽水、QQ 音乐、网易云、酷狗、全民 K 歌、配音秀、松果时刻

**其他：** 番茄小说 / 红果短剧 / 红果漫剧、央视、央视频、腾讯频道

**明确不做：** 私密内容、VIP/付费破解、爱优腾芒/Netflix 等版权长片、DRM。

## 6. 本仓库「正式承诺」建议

对外开放时不要把 50 个平台都写成 SLA。建议对外承诺三档：

| 档 | 平台 | 承诺 |
| --- | --- | --- |
| A 已实测 | 抖音视频/图文、小红书三态、B 站视频 | 家庭宽带出口下可用；抖音实况需有效运营 Cookie |
| B 声明支持未测 | 快手、微博、视频号、公众号等 | 尽力而为，可单独开关 |
| C 不承诺 | 付费、私密、版权长视频 | 接口应失败 |

A 档回归样本就是根目录 `测试集`。平台改版导致 A 档连续失败，应视为事故，而不是「文档写了支持」。
