# 解析 API 接口文档（对外）

面向接入方。生产环境必须使用 **HTTPS + API Key**。不要把平台 Cookie 发给本接口，也不要在客户端保存运营账号。

- 服务端口（源站）：`8051`
- 对外基址：`https://{你的域名}`（由反代终止 TLS）
- 编码：`UTF-8`
- 标准解析路径：`/api/v1/parse`

---

## 1. 鉴权

运营模式（`API_ONLY=false`，对外开放必须用这个）：

```http
Authorization: Bearer mp-xxxxxxxxxxxxxxxxxxxxxxxx
```

备用：`?key=mp-xxxxxxxxxxxxxxxxxxxxxxxx`（日志和 Referrer 容易泄漏，不推荐）。

无 Key、Key 无效、账号停用/过期分别返回 `401` / `403`，见错误码表。

管理员在控制台创建 Key，格式为 `mp-` + 24 位字符。请按应用拆 Key，不要共用。

---

## 2. 健康检查

```http
GET /api/health
```

成功：

```json
{ "status": "ok" }
```

用于负载均衡与监控。此接口不解析作品。

## 3. 解析作品

### 3.1 请求

```
POST /api/v1/parse
GET  /api/v1/parse
```

`POST` 推荐。`Content-Type`：`application/json` 或 `application/x-www-form-urlencoded`。

| 字段 | 位置 | 必填 | 说明 |
| --- | --- | --- | --- |
| `url` 或 `text` | JSON / 表单 / Query | 是 | 分享链接，或整段口令（服务端会抽出 URL） |
| 文本长度 | — | — | 最长 **2000** 字符 |

支持直接粘贴：

```text
6.43 复制打开抖音，看看【某某的图文作品】…… https://v.douyin.com/xxxx/
```

JSON 示例：

```bash
curl -sS -X POST "https://{你的域名}/api/v1/parse" \
  -H "Authorization: Bearer mp-你的密钥" \
  -H "Content-Type: application/json" \
  -d "{\"url\":\"https://v.douyin.com/jL1gk2Mu-GM/\"}"
```

GET 示例（仅调试）：

```text
GET /api/v1/parse?url=https://b23.tv/4JtglDc
Authorization: Bearer mp-你的密钥
```

超时：请把客户端超时设到 **120 秒**。服务端单次解析预算约 90 秒。

### 3.2 成功响应

HTTP 200，且 `succ` 为 `true`。

```json
{
  "retcode": 200,
  "retdesc": "成功",
  "succ": true,
  "data": {
    "platform": "抖音",
    "video_id": "7700408319630312933",
    "title": "作品标题或文案",
    "desc": "完整文案",
    "video_url": "https://...",
    "cover_url": "https://...",
    "audio_url": null,
    "author": {
      "nickname": "作者昵称",
      "author_id": "...",
      "avatar": "https://..."
    },
    "image_list": []
  }
}
```

`data` 字段说明：

| 字段 | 类型 | 何时出现 |
| --- | --- | --- |
| `platform` | string | 总是 |
| `video_id` | string | 能从 URL 解析到 ID 时 |
| `title` | string | 无标题时等于文案 |
| `desc` | string | 原文案 |
| `video_url` | string \| null | 有主视频时 |
| `video_list` | string[] | **仅多视频/合集**；有则第一项与 `video_url` 相同 |
| `cover_url` | string \| null | 无封面时用图集第一张 |
| `audio_url` | string \| null | 有独立音频时 |
| `author` | object \| null | `nickname` / `author_id` / `avatar` |
| `image_list` | array | 图文/图集/实况；实况对象可含 `live_asset_url` |
| `subtitles` | array | `{start, end, text}`，平台提供时 |
| `is_preview` | boolean | 仅试听音频 |
| `full_duration` | number | 仅试听音频，整曲秒数 |

`image_list` 两种元素：

```json
[
  "https://.../static.jpg",
  {
    "url": "https://.../still.jpg",
    "live_photo_url": "https://.../live.mp4",
    "live_asset_url": "https://.../api/v1/live-photo/AbCd1234/LIVEMP.jpg"
  }
]
```

接入建议：

1. 有 `video_url` 当视频；`image_list` 非空当图集；两者都有（小红书视频封面）以视频为主、图片当封面。
2. 实况：`live_asset_url` 是 `/LIVEMP.jpg` 的 Motion Photo JPEG。快捷指令 1.8 只存这一份，不再把动轨另存成视频。
3. **立刻下载**返回的 CDN 地址和 `live_asset_url`。CDN 带签名稍后会 403；合成地址约 2 小时有效。
4. 不要假设无水印。个别平台（即梦、小云雀、元宝视频等）官方说明可能带原生水印。

### 3.3 失败响应

HTTP 状态码与 `retcode` 一致。`succ` 为 `false`，`data` 为 `null`，以 `error_code` 做分支。

```json
{
  "retcode": 400,
  "retdesc": "该链接尚未支持提取",
  "succ": false,
  "data": null,
  "error_code": "PLATFORM_NOT_SUPPORTED"
}
```

## 4. 错误码

| HTTP | error_code | 含义 | 调用方怎么做 |
| ---: | --- | --- | --- |
| 400 | `INVALID_TEXT` | 空参数 | 检查 body |
| 400 | `TEXT_TOO_LONG` | 超过 2000 字符 | 只传链接 |
| 400 | `URL_NOT_FOUND` | 文本里没有 URL | 检查口令是否完整 |
| 400 | `REDIRECT_FAILED` | 短链打不开 | 重试一次；仍失败换长链 |
| 400 | `PLATFORM_NOT_SUPPORTED` | 域名不在支持表 | 不要重试 |
| 400 | `MEDIA_NOT_FOUND` | 页面上抽不到媒体 | 有限重试 1 次 |
| 400 | `MEDIA_DELETED_OR_PRIVATE` | 删除/私密/日常 | **不要重试** |
| 400 | `NO_MEDIA_IN_CONTENT` | 纯文本分享 | 不要当媒体 |
| 400 | `XIAOHONGSHU_COOKIE_REQUIRED` | 小红书风控 | 联系运营，不是换 Key |
| 400 | `KUAISHOU_COOKIE_REQUIRED` | 快手风控 | 同上 |
| 400 | `PINDUODUO_COOKIE_REQUIRED` | 拼多多凭证 | 同上 |
| 400 | `WECHAT_CHANNELS_COOKIE_REQUIRED` | 视频号/元宝凭证 | 同上 |
| 401 | `API_KEY_REQUIRED` | 没带 Key | 加 Header |
| 401 | `INVALID_API_KEY` | Key 无效 | 核对 Key |
| 402 | `INSUFFICIENT_CREDITS` | 积分用尽 | 找管理员 |
| 403 | `API_KEY_DISABLED` | Key/账号停用 | 找管理员 |
| 403 | `ACCOUNT_EXPIRED` | 账号过期 | 找管理员 |
| 403 | `DEMO_DISABLED` | 体验接口未开放 | 改走 `/api/v1/parse` + Key |
| 429 | `RATE_LIMITED` | 账号/Key QPS | 降速，指数退避 |
| 429 | `PLATFORM_RATE_LIMITED` | 单平台 QPS | 对该平台降速 |
| 503 | `API_DISABLED` | 全局维护 | 等恢复 |
| 503 | `PLATFORM_DISABLED` | 该平台关闭 | 换内容或等恢复 |
| 504 | `PARSE_TIMEOUT` | 解析超时 | 可重试 1 次 |
| 500 | `INTERNAL_ERROR` | 服务器异常 | 可重试 1 次 |

`retdesc` 有时是平台原文（例如权限提示），请展示给用户，但分支只认 `error_code`。

## 5. 当前可接入平台（对外承诺）

以本仓库 `测试集` 实测为准（2026-10-26）：

| 平台 | 形态 | 状态 |
| --- | --- | --- |
| 抖音 | 公开视频、公开图文 | 可用 |
| 抖音 | 实况 / Live Photo | 可用，依赖服务端运营登录态 |

更多平台见内部《实现与支持范围》。未列入上表的，按「尽力支持、可能随时关闭」处理。请先发一条真实链接到测试环境，再写进你的产品。

不支持：私密作品、付费/会员专享、影视版权长视频、需要调用方登录才能看的内容。

## 6. 接入示例

### Python

```python
import requests

BASE = "https://{你的域名}"
KEY = "mp-你的密钥"

def parse(share: str) -> dict:
    r = requests.post(
        f"{BASE}/api/v1/parse",
        headers={"Authorization": f"Bearer {KEY}"},
        json={"text": share},
        timeout=120,
    )
    r.raise_for_status()
    body = r.json()
    if not body.get("succ"):
        raise RuntimeError(body.get("error_code"), body.get("retdesc"))
    return body["data"]

data = parse("https://v.douyin.com/jL1gk2Mu-GM/")
print(data["platform"], data.get("title"), data.get("video_url"))
```

### 建议的客户端逻辑

```
提交 text
  succ=true → 若 video_url 则下视频；遍历 image_list：实况对象先下 live_asset_url（.jpg）认成图片再存，并保存动轨；失败再存静图
  MEDIA_DELETED_OR_PRIVATE / PLATFORM_NOT_SUPPORTED / NO_MEDIA_IN_CONTENT → 提示用户，停止
  429 → 按 Retry-After 或 1s/2s/4s 退避
  401/402/403 → 检查 Key，不要对同一错误打爆
  *_COOKIE_REQUIRED → 提示「平台风控，请稍后」，并通知我们
```

---

## 7. 限额与合规

- QPS、积分、单平台开关由运营在后台配置，文档不写死数字。超限只会出现 `429` / `402`。
- 返回的媒体 URL 来自平台 CDN，版权仍归作者与平台。接入方需遵守各平台用户协议与当地法律，仅处理有权使用的公开内容。
- 本接口**不是**去水印或破解下载权限的工具。
- 禁止把本 API 做成未登录即可解析任意链接的公开网站；体验页有独立频控，生产流量必须走带 Key 的 `/api/v1/parse`。

---

## 8. 变更

路径与 `data` 字段集合保持向后兼容：只增字段、不改已有字段含义。某平台下线会走 `PLATFORM_DISABLED` 或 `PLATFORM_NOT_SUPPORTED`，不会改掉整包 JSON 形状。
