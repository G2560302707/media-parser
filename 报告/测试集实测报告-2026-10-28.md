# Media-Parser 测试集实测报告

- **测试日期**：2026-10-28
- **测试环境**：Windows 11 / Python 3.11.9 / 本机直启（非 Docker），`API_ONLY` 模式，**未配置任何平台 Cookie**，出口走本机代理
- **测试对象**：`测试集` 文件中全部 7 条真实分享链接（抖音 3、小红书 3、哔哩哔哩 1）
- **调用方式**：`POST /api/parse`（`{"text": "<原始分享文本>"}`），即用户实际复制粘贴的带噪音口令文本

> 环境说明：项目 app.py 依赖 Linux 的 `fcntl`，Windows 直接 `python app.py` 无法启动；本次测试通过外部垫片（stub fcntl + 安装 tzdata）启动，未改动仓库代码。另：服务进程需手动继承系统代理环境变量，否则 Python requests 无法出网（curl 不受影响）。

## 二、亮点（表现好的能力）

1. **分享文本抗噪提取**：抖音口令中混有乱码（`X@M.WZ`、`:0pm anQ:/`）、emoji、话题标签，3 条全部正确抽出短链并解析。
2. **抖音图集高清大图**：24 张图全部为高清原图（q80，单张 0.3~1.1MB），非缩略图。
3. **小红书实况完整提取**：5 张图全部附带 `live_photo_url` 动轨，11 个媒体 URL 全部可下载 —— 无 Cookie 情况下小红书实况能力完整。
4. **媒体 URL 可用性 100%**：全部 44 个媒体 URL 实测可下载（HTTP 200，含 Range 分段）。小红书/B站 CDN 返回 403、抖音部分节点返回 405 均为防盗链对 HEAD/无 Referer 请求的正常拦截，携带平台 `Referer` 后全部可下载 —— 这是使用方（前端/下载器）必须带 Referer 的正常约束，不是解析缺陷。
5. **无 Cookie 响应速度**：B站/小红书 ≤1.3s，抖音 2.4~3.1s（含短链重定向），无代理池情况下表现良好。
6. **字段契约完整**：`platform/title/desc/video_url/audio_url/cover_url/author(nickname+avatar)/image_list` 均有值，`video_url` 已统一 HTTPS 并去重。

## 三、发现的问题

### P1｜抖音实况（Live Photo）无 Cookie 时降级为静态图
- **现象**：案例 3 返回 1 张静态图，无 `live_photo_url`；而 README 平台矩阵标注抖音支持"实况 ✓"。
- **根因（已复现）**：抖音 Web Detail API（含 LivePhoto 视频流元数据）被 `ArgusSecurityPlugin Uifid Not Found` 403 拦截（无 Cookie/无 uifid），解析器回退到 share-page SSR 通道；该通道对普通视频/图集完整，但实况动轨仅存在于 Detail API 中，SSR 只有静态图。本次测试抖音 3 条全部走 SSR 通道（日志确认 8 次 Argus 403）。
- **影响**：未配置抖音 Cookie 的部署下，实况作品静默丢失动轨（用户拿到的是"不会动"的图），且响应无任何标记提示降级。
- **建议**：① 在文档/README 标注"抖音实况需配置 Cookie"；② 解析结果中增加 `is_preview` 或 `degraded` 类标记；③ 评估从 SSR 页面内嵌数据中补抓实况 uri 的可行性。

### P2｜抖音视频无字幕返回
- 案例 1 视频未返回 `subtitles`。README 标注抖音支持字幕 ✓，可能该视频本身无 CC 字幕（未深究），但建议对"无字幕"与"未提取"做区分测试。

### P3｜Windows 平台开箱不可用（非本次链接解析问题）
- `app.py` 顶部 `import fcntl`、`src/db.py` 依赖 `zoneinfo` 时区数据（Windows 需 `pip install tzdata`），Windows 本机 `python app.py` 直接崩溃。仅影响 Windows 开发者本机调试，Docker/Linux 部署不受影响。

### P4｜进程不继承系统代理
- 依赖环境变量而非 Windows 系统代理设置；未设置 `HTTP(S)_PROXY` 时 requests 直连超时（首测 7/7 失败即由此导致）。对国内服务器部署无影响，但在需要代理的海外部署场景容易踩坑，建议文档注明。

## 四、结论

在**零 Cookie、无代理池**的最严苛条件下，测试集 7 条链接：**6 条完整成功、1 条实况降级（仍有可用静态图）**，所有解析出的媒体地址均真实可下载。核心解析能力（视频直链、高清图集、小红书实况、口令文本提取）达到 README 宣称水平；抖音实况是无 Cookie 环境下的已知短板，建议补充降级标记与文档说明。
