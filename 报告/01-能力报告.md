# media-prism 能力报告

- 对象：自建解析 API（本仓库仅保留 media-prism）
- 实测日期：2026-10-26
- 样本：工作区 `测试集`（抖音 / 小红书 / B 站）
- 结论先看：**这套测试集上，media-prism 是可落地的解析内核；不是所有形态都能匿名通吃。**

---

## 1. 产品能做什么

对外只做一件事：调用方提交公开分享链接或口令文本，服务返回该作品的**标题、作者、封面、视频直链、图集、实况轨、音频、字幕**（平台有什么给什么）。

- 不转码、不去水印。所谓无水印，是选取平台已经下发的原始/无水印 CDN 地址。
- 不下载到服务器再转发。默认只返回 URL，由调用方在有效期内自行拉取。
- 不解析私密、仅好友可见、会员付费、爱优腾等版权长视频。

## 3. 能力边界（必须写进对外说明）

| 能力 | 状态 |
| --- | --- |
| 抖音短视频、普通图文 | 匿名可用 |
| 抖音 Live Photo / 实况 | 要运营账号 Cookie；机房 IP 更容易失败 |
| 小红书短链 | 本机匿名可用；机房 IP 常跳登录，需 `XHS_COOKIE` |
| B 站普通视频 | 匿名可用 |
| 视频号 | 声明支持，但必须配置腾讯元宝 Cookie，本仓库未实测 |
| 快手 / 微博等 | 声明支持，风控时要 Cookie，未用测试集覆盖 |
| 私密 / 日常 / 已删除 | 明确失败，不重试 |
| 会员、付费、版权长视频 | 项目原则不做 |
| 保证直链永久有效 | 不能保证。CDN 带签名，通常数十分钟到数小时失效 |

解析成功 ≠ 调用方有权分发。没开官方「允许下载」的作品，播放地址仍可能被抽出，这只是平台下发了播放流，不是授权。

## 4. 稳定性判断

media-prism 靠各平台网页/接口结构工作。结构一改，对应解析器会挂。这不是 yt-dlp 那种多年提取器，而是**要按平台做巡检的服务**。

可接受的线上姿态：

1. 核心三平台（抖音、小红书、B 站）每日用固定公开链接巡检。
2. 单平台失败可在后台关掉该平台，不必停整站。
3. Cookie 失效只影响实况、视频号、部分小红书，普通抖音视频应仍可用。

---

## 5. 给决策用的一句话

要做国内短链解析 API：**用 media-prism 做内核**；把抖音实况和小红书风控当成「要养号、要对出口 IP」的有状态能力，不要当成无状态 CDN。
