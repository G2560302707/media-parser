# iOS 快捷指令能力范围

- 日期：2026-10-29
- 指令版本：**媒体解析 1.5**（HubSign 签名，`shortcuts/媒体解析.shortcut`）
- 源码：`shortcuts/媒体解析.cherri`
- 接口：`POST https://after7lab.cloud:81/api/v1/parse`，Header `Authorization: Bearer mp-...`
- 本文说明**现在手机上实际能做什么**，不是设计稿。设计背景见 [05-iOS快捷指令设计文档.md](./05-iOS快捷指令设计文档.md)。

换指令可以把 `.shortcut` AirDrop 到手机覆盖安装，不必出新的 Docker 包。评论区拿图已撤销，接口不再接受 `mode=comments`。

---

## 1. 日常怎么用

1. 首次：把 `mp-` 开头的密钥贴进指令，记在 iPhone「快捷指令」文件夹 `媒体解析/api-key.txt`。更新指令不会冲掉密钥。
2. 在抖音 / 小红书点分享，选「媒体解析」（也可复制口令后点桌面图标，或从剪贴板读入）。
3. 直接解析并保存这条**作品**的视频 / 图 / 实况 / 音频。
4. 成功则进系统相册「最近项目」，并出一条通知。
5. 每次运行都往 `媒体解析/诊断日志.txt` 追加日志，失败时可打开或复制。

没有密钥、次数用完、账号到期，会打开网站控制台，不在指令里做付费。

## 2. 已完成（作品）

已在 iOS 上用过，当前范围如下。

| 能力 | 现状 |
| --- | --- |
| 分享口令 / 链接原样提交 | 已完成。整段抖音口令可直接进 `text` |
| 必须带 API Key | 已完成。没有 Key 走首次配置，无效 Key 可当场更换 |
| 视频存相册 | 已完成。`video_url` 以及 `video_list` 里以 `http` 开头的地址才会下载 |
| 图文 / 图集存相册 | 已完成。`image_list` 支持纯 URL 或 `{url, live_photo_url}`；有实况时优先下实况 |
| 音频 | 已完成。存到 `媒体解析/音频.m4a`，不进相册 |
| 空地址不下载 | 已完成。iOS 把空字符串也当成「有值」，必须 `beginsWith "http"` 才调用下载，避免「未指定 URL」 |
| 成功判定 | 已完成。不检查 JSON 字典「有没有值」（iOS 26/27 会误判），看 `retcode` / `succ` / `platform` 字符串 |
| 保存位置 | 已完成。写入系统「最近项目」；不能可靠指定自定义相册名 |
| 限流重试 | 已完成。`RATE_LIMITED` / `PLATFORM_RATE_LIMITED` 等 1 秒再请求一次 |
| 积分 / 到期 / 停用 | 已完成。弹窗说明并打开控制台 |
| 诊断日志 | 已完成 |

平台范围与网站解析一致：分享链接能解析的平台都可以走指令。实测重点是抖音视频、抖音图文、小红书。封面默认不下。

## 3. 明确不做

- 不从评论区下图或动图。抖音网页评论接口主要是热门列表，App 里刚发的评论经常拿不到，因此整段能力已去掉。
- 不在网页上停下来完成保存（作品路径是原生下载）。
- 不把密钥写进 `.shortcut` 文件。
- 不做 OAuth、扫码、邮箱魔法链接。
- 不指定自定义相册名称（iOS 用文本当相册名会失败）。
- 不在 Windows 上生成可被所有 iPhone 当「官方签名」导入的文件；当前是 HubSign 代签，AirDrop 导入。
- 网站 `/shortcut.shortcut` 仍可能是后台上传覆盖或旧的网页跳转版；手机日常用仓库里这份签过名的 1.5。

## 4. 文件与部署关系

| 文件 | 用途 |
| --- | --- |
| `shortcuts/媒体解析.cherri` | 源码（LF） |
| `shortcuts/媒体解析_unsigned.shortcut` | 未签名 plist，供 HubSign |
| `shortcuts/媒体解析.shortcut` | 已签名，发给 iPhone |
| 后台「系统设置 → iPhone 快捷指令」 | 上传或填 iCloud 链接即可换指令，不必重新打镜像 |

手机请换成 **1.5**，去掉「存评论里的图或动图」菜单。线上若仍是带评论接口的旧后端，多出来的 `mode` 参数会被忽略，不影响存作品；要让接口也去掉评论模式，需要再部署一版后端。
